# Lembretes — Programação III UMFG 2026

- `api/` — Minimal API (.NET 8 + MySQL)
- `front/` — Front-end (HTML, CSS e JavaScript)

## Executar

1. MySQL em `localhost:3306` (usuário `root`, senha `root`).
2. API: `cd api/umfg.programacaoiii.minimalapi.2026` e `dotnet run --launch-profile http` (http://localhost:5207).
3. Front-end: abrir `front/index.html` com o Live Server.
